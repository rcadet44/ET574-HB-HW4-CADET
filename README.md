# Dice Game Simulator

## Project Description
This project is a simple Python dice game
that simulates rolling two dice.

## Features
- Roll two dice.
- Calculate the total of both dice.
- Evaluate the game outcome.
- Play multiple rounds.
- Exit the game.

## Files
- main.py: Contains the main game code.
- test_dicegame.py: Contains unit tests.

## How to Run
Run the following command:

python main.py

## Unit Testing
Run the tests using:

python -m unittest test_dicegame.py
